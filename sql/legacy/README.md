# SQL của phiên bản cũ

Các file ở đây dùng schema trước phiên bản `cms_logistics` gồm 10 bảng.
Chỉ giữ để tham khảo lịch sử; không chạy lên database hiện tại.

Cài mới bằng `../cms_logistics_schema.sql`, sau đó lần lượt chạy các file
`cms_logistics_procedures.sql`, `cms_logistics_customers.sql`,
`cms_logistics_orders.sql`, `cms_logistics_fulfillment.sql` và
`cms_logistics_payments.sql` trong thư mục cha.

Các tài khoản mẫu và bảng tỷ giá/biểu phí trong thư mục này không đại diện cho
database đang chạy. Collection Postman hiện tại nằm trong `Gateway/postman`.
